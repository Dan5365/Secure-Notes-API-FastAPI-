# FastAPI MyNotesApp

Проект на **FastAPI**, предоставляющий полноценную систему для работы с пользователями и заметками.  
С помощью этого приложения можно быстро создавать и управлять заметками, обеспечивая безопасный доступ через **JWT-токены**.  

Особенности проекта:  
- Полная регистрация и авторизация пользователей с защитой данных.  
- CRUD для заметок: создание, чтение, редактирование и удаление.  
- Разделение ролей пользователей: администраторы могут управлять всеми пользователями, обычные пользователи — только своими заметками.  
- Работа с базой данных через **SQLAlchemy 3.0**, одна из новейших версий библиотеки, обеспечивающая современный и удобный синтаксис для работы с БД.  
- Поддержка современного веб-документирования API через **Swagger UI** и **Redoc**.  
- Проект структурирован так, чтобы легко добавлять новые функции и масштабировать.  

 **Примечание:**  
В проекте использованы новейшие библиотеки и инструменты Python, такие как **FastAPI**, **SQLAlchemy 3.0**, **Pydantic**, **Passlib** для хэширования паролей, что делает код современным и совместимым с последними стандартами разработки.  

Этот проект — отличная база для изучения FastAPI, построения собственного приложения с авторизацией и управления данными пользователей, а также практики работы с современными инструментами Python для веб-разработки.

## Структура проекта

```
FastAPIProject/
├─ .venv/ # Виртуальное окружение (не включать в git)
├─ routers/
│ ├─ notes.py # Роуты для заметок
│ ├─ users.py # Роуты для пользователей
├─ auth.py # Авторизация и JWT
├─ crud.py # Функции работы с БД
├─ database.py # Настройка базы данных
├─ main.py # Основной файл приложения FastAPI
├─ models.py # SQLAlchemy модели
├─ schemas.py # Pydantic схемы
├─ users.db # База данных SQLite
├─ API test_main.http # Тестовые HTTP-запросы (для VSCode REST Client)
```

## Установка

1. Клонировать репозиторий:  
```bash
git clone <repo_url>
cd FastAPIProject
```
## Создать и активировать виртуальное окружение:
```
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/Mac
source .venv/bin/activate
```
## 3. Установить зависимости:
pip install fastapi uvicorn sqlalchemy passlib[bcrypt] python-multipart jwt

## Запуск приложения
```
uvicorn main:app --reload
```

## Однако для быстрого запуска рекомендую:
```
python main.py
```
Приложение будет доступно по адресу: http://127.0.0.1:8000

Swagger UI: http://127.0.0.1:8000/docs
Redoc: http://127.0.0.1:8000/redoc

## Функционал

- Регистрация и вход пользователей (JWT авторизация)

- CRUD для заметок (только для авторизованных пользователей)

- Разделение ролей пользователей (admin/creator и обычный пользователь)

- Админ может просматривать список пользователей и назначать роли

## Примеры запросов

- Регистрация пользователя: POST /users/register

- Вход пользователя: POST /users/login

- Создание заметки: POST /users/notes (только авторизованный пользователь)

Просмотр заметок: GET /users/notes

Настройка базы данных

Используется SQLite: users.db

Модели описаны в models.py

Инициализация таблиц выполняется в database.py

Важно

Не коммитить .venv/

Пароли хранятся в хэшированном виде с использованием bcrypt
